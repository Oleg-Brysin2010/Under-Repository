### 📝 Описание проекта
Репозиторий для автоматического обновления проектов на моём купленном выделенном сервере. Здесь собраны исходные коды Telegram-ботов, конфигурации личного VPN и файлы управления приватным сервером Minecraft.

---

### 🗂️ Детальная структура репозитория

#### 🤖 Telegram и Twitch боты
*   🧠 **`ai-bot`** — Продвинутый Telegram-бот на базе **GPT-4**. Он очень хорошо обучен, знает ваше имя в Telegram и перечитывает всю историю чата, чтобы идеально помнить контекст разговора. При необходимости всю память бота можно полностью очистить с помощью команды `/clear`.
*   🔔 **`under-bot`** — Специальный бот для Telegram, который мгновенно присылает важные уведомления из социальной сети **Under**.
*   🎮 **`twitch-bot`** — Бот-трекер, который круглосуточно следит за каналом стримера **Сфинкса**. Как только Сфинкс запускает трансляцию, бот автоматически отправляет уведомление об этом в привязанные группы.

#### ⛏️ Игровые серверы
*   🌍 **`minecraft`** — Настройки и файлы закрытого сервера **Minecraft Bedrock**. Это приватный сервер, на котором играем только я и моя сестра. Здесь бережно хранится и работает наш старый совместный мир.

#### 🌐 Сетевые инструменты
*   🇳🇱 **`vpn-sub`** — Конфигурация, которая превращает выделенный сервер в персональный **VPN**. Доступны надежные серверы в Нидерландах с автоматической встроенной блокировкой рекламы.
