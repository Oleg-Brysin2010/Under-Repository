### 📝 Описание проекта
Репозиторий для автоматического обновления проектов на моём купленном выделенном сервере. Здесь находятся исходные коды Telegram-ботов (таких как AI и Under), Twitch-бота, конфигурации VPN, а также файлы управления сервером Minecraft.

---

### 🗂️ Структура репозитория

*   🤖 **`ai-bot`** — Исходный код и конфигурации Telegram-бота AI.
*   🤖 **`under-bot`** — Исходный код и настройки Telegram-бота Under.
*   🎮 **`twitch-bot`** — Скрипты и интеграции для Twitch.
*   ⛏️ **`minecraft`** — Скрипты запуска, плагины и конфигурационные файлы игровых серверов Minecraft.
*   🌐 **`vpn-sub`** — Скрипты автоматизации и настройки VPN-конфигураций.
*   🚀 **`setup.sh`** — Главный bash-скрипт для быстрой инициализации и развертывания всего окружения на сервере.

---

### 🚀 Быстрый запуск

Чтобы развернуть проекты на вашем сервере, выполните команды в терминале:

```bash
git clone https://github.com
cd Under-Repository
chmod +x setup.sh
./setup.sh
```
